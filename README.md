# Bank Account App

A simple command-line banking program written in Python. It lets a user
deposit and withdraw money, check their balance, and saves the balance
to a file so it persists between sessions.

## Features

- Deposit and withdraw funds
- Prevents overdrawing (can't withdraw more than the balance)
- Menu-driven interface
- Saves balance to a file, so it's remembered after closing the program

## What I learned building this

- Object-oriented programming: classes, methods, and attributes
- Reading from and writing to files
- Handling errors with try/except
- Building an interactive menu loop

## How to run

1. Make sure Python is installed
2. Run the program:
   python Bank_account.py
